# deepseek-chat-manager

[English](README.md) | 简体中文

本项目在官方 [chat-demo](https://github.com/deepseek-ai/chat-demo) 基础上二次开发，重点增强历史对话的搜索、导出与旧版数据兼容导入能力。

克隆本项目后即可本地运行；也可执行 `pnpm build` 生成 `dist/`，部署到静态服务器或直接打开 `dist/index.html`。导入导出对话数据无需 API Key；首次进行会话（聊天）时，请在设置中填写 API Key。

## 运行

准备 Node.js 20.19+（或 22.12+）和 pnpm：

```sh
git clone https://github.com/skyboyhjj/deepseek-chat-manager.git
cd deepseek-chat-manager
pnpm install
pnpm dev
```

打开 http://localhost:8090 。

生成静态产物：

```sh
pnpm build
```

产物位于 `dist/`，可部署到静态服务器，也可直接打开 `dist/index.html`。直接打开时，浏览器和 API 服务需允许 `file://` 页面的存储与跨域请求。

## 功能

- 多会话、自动标题、重命名与删除；编辑提问、重新生成和切换消息分支。
- 流式回答、深度思考、智能搜索、链接阅读与来源引用；支持停止和符合条件的继续生成。
- 附件上传、粘贴与拖拽，语音输入和回复朗读；移动端录音时输入框首行显示实时频谱。
- Markdown、代码高亮、KaTeX 公式和 Mermaid 图表。
- 简体中文与英文、浅色与深色主题、移动端布局、位置设置、历史导入导出。
- 全局搜索：跨全部会话检索对话内容。
- 搜索导出：按关键词检索全部对话，支持匹配方式（OR/AND）、标签策略、提取粒度（聚焦片段/整篇提取）与日期范围，导出为 Markdown / CSV / JSONL。
- 历史导入导出：导出全部会话及图片原件为 ZIP，并兼容导入旧版本 DeepSeek 导出的 ZIP（`conversations.json` 格式）。

## 数据

API Key 和设置保存在浏览器 localStorage，会话及附件原件保存在 IndexedDB，本地数据按浏览器用户配置和站点源（origin）隔离。发送对话、上传附件和使用语音功能时，相应内容会提交给配置的 API 服务。

设置中的历史导入导出使用 ZIP 格式。导入会在确认并校验成功后替换全部本地会话和附件；导出包含会话与本地可用的图片原件，不包含 API Key、设置或非图片附件原件。格式与保留范围见[历史导入导出](src/services/chat/history/README.md)。导入同时兼容旧版本 DeepSeek 导出格式（无 `manifest.json`、单文件 `conversations.json`）。

设置 → 数据管理 → 删除所有对话，会在确认后清空全部本地会话、附件原件和未发送的草稿，停止正在生成的回复并回到新对话。API Key 和其他设置保留，已上传到 API 服务的文件不受影响。

## 开发

| 命令          | 用途                |
| ------------- | ------------------- |
| `pnpm dev`    | 启动开发服务器      |
| `pnpm build`  | 构建到 `dist/`      |
| `pnpm type`   | TypeScript 类型检查 |
| `pnpm lint`   | oxlint 检查         |
| `pnpm format` | oxfmt 格式化        |

[rspack.config.ts](rspack.config.ts) 默认连接 `https://api.deepseek.com`。`createConfig({ apiOrigin, devServer })` 支持自定义 API 地址和开发服务器代理。

聊天默认使用 `deepseek-flash`，通过 Anthropic 兼容的 Messages / Files API 通信；语音使用 ASR / TTS 接口。请求使用搜索、链接阅读、标题和 `latest_reminder` 等扩展，接入服务需支持相应能力。附件实际支持的格式以服务端校验为准。

```text
src/
  app/                 应用布局、主题与全局样式
  components/          聊天、设置、Markdown 等界面组件
  i18n/                中英文文案
  services/
    api/               API 请求、SSE 与协议类型
    chat/              会话、消息分支、本地存储与历史导入导出
    markdown/          Markdown 解析、代码高亮与图表
    speech/            录音与朗读
  utils/               通用工具
```
