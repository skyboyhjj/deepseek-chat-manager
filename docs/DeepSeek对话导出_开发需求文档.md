# DeepSeek 对话导出工具 — 开发需求文档

> 版本：v1.0
> 状态：需求初稿（待评审）
> 定位：将 DeepSeek 官方导出的对话数据，转化为可用于报告撰写、主题分析、内容分享的结构化素材

---

## 一、项目概述

### 1.1 背景

用户经常需要从 DeepSeek 导出的 `conversations.json` 中，按主题（如「道境坐标系」「道德经二十七章」「痛苦」「成才」「领域」等）提取相关对话内容，并整理成 Markdown 报告、CSV 明细等交付物。当前依赖临时脚本 + 人工操作，流程分散、不可复用。

### 1.2 目标

构建一个「对话导出」工具（Skill 或脚本集），支持：

- 一键解析 DeepSeek 对话数据
- 按关键词/主题检索与筛选
- 提取相关内容并自动打标签
- 导出为 Markdown / CSV 等多种格式

### 1.3 用户与场景

| 用户 | 场景 |
|---|---|
| 内容创作者 | 从海量对话中提取某主题，整理成文章/讲稿 |
| 研究者 | 统计关键词分布，做主题分析 |
| 普通用户 | 备份、检索、分享自己的对话 |

---

## 二、输入与输出定义

### 2.1 输入

| 项 | 说明 |
|---|---|
| 文件 | `conversations.json`（DeepSeek 官方导出） |
| 检索条件 | 一组关键词（可多个，支持主题词） |
| 导出选项 | 格式（MD / CSV / TXT）、粒度（聚焦片段 / 整篇对话） |

### 2.2 输出

| 格式 | 内容 | 用途 |
|---|---|---|
| `.md` | 按「对话标题 / 角色」分段的读解文档、报告、讲稿 | 阅读、分享、出版 |
| `.csv` | 结构化明细，含元数据 | Excel 分析、筛选、统计 |
| `.txt` | 中间提取草稿 | 调试、二次加工 |

CSV 统一使用 `utf-8-sig` 编码（含 BOM），保证 Excel 打开中文不乱码。

---

## 三、数据结构字段定义

### 3.1 源数据结构（DeepSeek 导出）

```
conversations[]              # 对话列表
  ├─ title                   # 对话标题
  └─ mapping{}               # 消息节点映射
       └─ message
            └─ fragments[]   # 消息片段
                 ├─ content  # 文本内容
                 └─ type     # REQUEST=用户 / RESPONSE|TEXT=助手
```

### 3.2 导出明细字段（CSV）

| 字段 | 类型 | 说明 |
|---|---|---|
| 对话标题 | string | 命中消息所属对话 |
| 角色 | enum | 用户 / 助手 |
| 主题标签 | string | 归一后的标签（如「时位轴·熵流脉动」） |
| 命中关键词 | string | 实际命中的原始关键词 |
| 上下文 | string | 该消息完整文本 |

## 四、功能清单

### F1 数据解析
- 读取并解析 `conversations.json`
- 提取对话标题、消息正文、角色类型
- 容错处理：缺失字段（`title`、`mapping`、`fragments`）时跳过不报错

### F2 关键词检索与统计
- 支持多关键词组合命中检测
- 输出每个关键词的命中频次统计（词频分布）
- 输出命中的对话索引 + 标题，便于定位

### F3 内容提取（两种粒度）
- **聚焦提取**：仅抽取命中关键词的消息片段
- **整篇提取**：抽取命中的完整对话（含全部消息）

### F4 结构化打标签
- 每条命中记录附加：对话标题 / 角色 / 主题标签 / 命中关键词 / 上下文
- 支持「关键词 → 主题标签」的归一映射（可配置）

### F5 多格式导出
- Markdown：按对话 / 角色分段的读解文档
- CSV：结构化明细（见 3.2 字段表）
- 纯文本：中间草稿

### F6 统计概览
- 汇总：总命中条数、各关键词分布、涉及对话数
- 作为导出前的整体把脉输出

## 五、关键规则与约束

1. **编码**：所有输出文件统一 UTF-8；CSV 用 `utf-8-sig`（BOM）
2. **角色映射**：`REQUEST → 用户`；`RESPONSE` / `TEXT → 助手`
3. **命中规则**：一条消息命中多个关键词时，默认取首个命中的关键词打标签（可配置为全部记录）
4. **幂等性**：重复运行应得到一致结果
5. **可扩展**：关键词列表、标签映射应为可配置项，不硬编码

## 六、验收标准

| 编号 | 验收项 | 通过标准 |
|---|---|---|
| A1 | 解析正确 | 对话数、消息数与源文件一致 |
| A2 | 检索准确 | 命中关键词的消息全部被提取，无误命中 |
| A3 | 角色正确 | 用户/助手分类无错误 |
| A4 | CSV 可读 | Excel 打开无乱码，列完整 |
| A5 | 统计正确 | 命中总数与人工抽样结果一致 |
| A6 | MD 结构清晰 | 对话/角色分段正确，可直接阅读 |

---

## 七、非功能需求

- **性能**：处理 1 万条消息规模的数据应在秒级完成
- **健壮性**：字段缺失、空消息、异常编码时不崩溃
- **可维护性**：关键词与标签映射集中配置，便于复用
